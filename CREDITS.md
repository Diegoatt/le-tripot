# Crédits

## Sons
Aucun fichier audio. Tous les sons et la musique d'ambiance sont synthétisés à la volée avec la Web Audio API (`src/audio/sfx.ts`).

## Polices (embarquées, aucune requête réseau)
- **Bebas Neue** par Dharma Type, SIL Open Font License 1.1, via `@fontsource/bebas-neue`.
- **Inter** par Rasmus Andersson, SIL Open Font License 1.1, via `@fontsource/inter`.

## Emojis
Les avatars, symboles de la machine à sous et coureurs sont des emojis Unicode rendus par la police système (Segoe UI Emoji sur Windows, Apple Color Emoji sur macOS). Aucune image n'est distribuée.
